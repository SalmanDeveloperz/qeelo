# Qeelo Ice Cream 🍦

An editorial, interactive web application for **Qeelo Ice Cream**, a boutique handmade ice cream brand based in Lahore, Pakistan. Built with modern Web technologies, the site highlights artisanal flavors, a multi-scoop signature palette experience, and physical store locations.

---

## 🌟 Features

* **Interactive Qeelo Palette:** A dynamic scroll-triggered hero reel showcasing featured flavors with unique color shifts, ambient moods, and custom imagery.
* **Menu & Flavors:** Interactive showcase of signature, seasonal, local, and classic ice cream flavors.
* **Store Locator:** View current operational locations and upcoming branches in Lahore.
* **Responsive Design:** Fully mobile-friendly and optimized for smooth scrolling across device sizes.

---

## 🛠️ Tech Stack

* **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **UI Components:** [radix-ui](https://www.radix-ui.com/)
* **Package Manager:** Bun / pnpm / npm

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js (v18 or higher) and a package manager installed (`npm`, `pnpm`, or `bun`).

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/SalmanDeveloperz/qeelo.git](https://github.com/SalmanDeveloperz/qeelo.git)
   cd qeelo

```

2. Install dependencies:
```bash
npm install
# or
pnpm install
# or
bun install

```


3. Start the development server:
```bash
npm run dev
# or
pnpm dev
# or
bun dev

```


4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Building for Production

To build the project for production, run:

```bash
npm run build

```

You can preview the production build locally with:

```bash
npm run preview

```
